# FlowPay Demo — Vercel

Статический адаптивный демонстрационный интерфейс цифрового кошелька.

## Деплой
1. Загрузите содержимое этой папки в новый GitHub-репозиторий.
2. Импортируйте репозиторий в Vercel.
3. Framework Preset: Other.
4. Build Command: оставить пустым.
5. Output Directory: `.`.
6. Нажмите Deploy.

Можно также перетащить папку в Vercel через поддерживаемый способ импорта проекта.

Все данные и действия демонстрационные. Нет подключения к банку, платёжному шлюзу или хранению пользовательских данных.
